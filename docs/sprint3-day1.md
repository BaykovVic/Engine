## feature/script-inspector

- **Исполнитель:** E3 (Редактор .NET)
- **Порядок реализации:** 2
- **Зависимости:** инспектор компонентов и `ComponentField` из Этапа 3; C-интерфейс скриптов реализуют контуры E5/E4

**Цель фичи:** выбор класса скрипта из списка и редактирование его полей в инспекторе.

**Описание фичи:** класс скрипта выбирается дропдауном (классы-наследники ScriptComponent), сериализуемые поля скрипта редактируются в инспекторе через C-интерфейс.

**Общий порядок реализации фичи:**
1. Дополнить `EditorSession` методами получения классов и записи полей скрипта.
2. Объявить P/Invoke скриптов в `EngineInterop`.

**Файлы фичи:**
1. `editor/avalonia/Engine/EditorSession.cs`
2. `editor/avalonia/Engine/EngineInterop.cs`

### Файл: `editor/avalonia/Engine/EditorSession.cs`

**Назначение файла:** дополнение сессии редактора работой с классами и полями скриптов.

**Пошаговое описание действий:**
1. Реализовать `ScriptClasses(current)` — получить имена классов-скриптов через C-интерфейс.
2. Реализовать `SetScriptField(id, component, field, value)` — запись поля скрипта.
3. Добавить `ComponentField.IsScriptClass` и включение сериализуемых полей скрипта в список компонента `sky.script`.

**Что должно быть в файле:**

*Структуры / классы / enum:*
- дополнение `ComponentField`: свойство `IsScriptClass`.

*Функции / методы:*
- `public List<string> ScriptClasses(string current)`
- `public void SetScriptField(ulong id, int component, int field, string value)`

*Логика функций / методов:*
- `ScriptClasses(current)` — получает через C-интерфейс имена классов-скриптов. Параметры: `current`. Возвращает: список классов для выпадающего списка.
- `SetScriptField(id, component, field, value)` — записывает поле скрипта.
- `ComponentField.IsScriptClass` — поле `class` рендерится выпадающим списком; сериализуемые поля скрипта добавляются к списку у компонента `sky.script`.

**Результат по файлу:** сессия отдаёт классы скриптов и пишет их поля.

**Критерий правильности по файлу:**
1. Дропдаун показывает классы-наследники ScriptComponent; правка поля скрипта применяется к инстансу в Play.

### Файл: `editor/avalonia/Engine/EngineInterop.cs`

**Назначение файла:** дополнение резолвера и P/Invoke-объявлений функциями скриптов.

- `sky_editor_script_field_value`

*Логика функций / методов:*
