# Спринт 1. День 5

## Контур E1 (Ядро и данные)

feature/core-tests

Цель фичи: проверить математику, объектный и компонентный миры.
Описание фичи (для чего): зафиксировать корректность фундамента тестами; зависит от math-and-handles, object-model, component-model.
Пошаговое описание действий:
Сделай файл tests/core_tests.cpp
В файле tests/core_tests.cpp должны быть проверки математики
В тесте должна быть реализована логика: повороты и композиция трансформов дают ожидаемые значения.
Сделай файл tests/world_tests.cpp
В файле tests/world_tests.cpp должны быть проверки объектного и компонентного миров
В тесте должна быть реализована логика: иерархия и мировые трансформы корректны; поле каждого из 5 типов пишется и читается без потерь.
На выходе должно получиться:
- tests/core_tests.cpp
- tests/world_tests.cpp
- библиотеки sky_core, sky_object, sky_component собраны и линкуются; тесты core_tests, world_tests зелёные
КРИТЕРИЙ ПРАВИЛЬНОСТИ: поворот (0,0,1) на 90° вокруг Y = (1,0,0)±1e-5; ребёнок (1,0,0) под родителем, повёрнутым на 90° вокруг Y, в мире = (0,0,-1); поле каждого из 5 типов записывается и читается без потерь.
