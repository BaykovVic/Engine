# Технические задания по контурам (весь срок)

Сквозные ТЗ на 8 недель — по одному на контур (роль). Каждый документ
собирает задачи контура из всех этапов в единое задание в формате
«Общее описание задач контура» → «На выходе должно получиться»
(фиксируемый результат этапа).

| Контур | ТЗ | Область ответственности |
|---|---|---|
| E1 | [role-E1.md](role-E1.md) | Ядро и данные: математика, объектная/компонентная модели, сцена, отмена, сборочная точка |
| E2 | [role-E2.md](role-E2.md) | Рендеринг: Vulkan-бэкенд, PBR, тени, построитель кадра |
| E3 | [role-E3.md](role-E3.md) | Редактор (.NET): интерфейс, компоновка, гизмо, инспектор |
| E4 | [role-E4.md](role-E4.md) | Рантайм и скриптинг: физика, хостинг .NET, проигрыватель |
| E5 | [role-E5.md](role-E5.md) | Пайплайн, ассеты, пакеты: сборка, CI, импортёры, менеджер пакетов |
| E6 | [role-E6.md](role-E6.md) | Data-oriented системы и производительность: ECS, синхронизация, системы, многопоточность |

ТЗ контура отвечает на вопрос «какие задачи решает исполнитель за весь
срок и какой результат фиксируется на каждом этапе». Пофайловая
детализация (какие файлы и методы создавать) вынесена в документы по
неделям: [week1-files.md](week1-files.md) … [weeks7-8-files.md](weeks7-8-files.md).
Точный список **всех файлов проекта и объявленных в них функций/методов**
(сгенерирован из репозитория, совпадает 1:1) — в
[files-manifest.md](files-manifest.md): это авторитетный перечень «какой файл
создать и какие методы в нём». 
Общая стратегия, состав команды и риски — в
[plan-8-weeks-team.md](plan-8-weeks-team.md).

Контур **E6** выделен из зоны рантайма (ECS), чтобы разгрузить E4; его
обязательный минимум (этапы 1–2) имеет срок **17 июля**.
