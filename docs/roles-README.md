# Индивидуальные ТЗ по ролям (весь срок)

Сквозные задания на 8 недель — по одному на роль. Каждый документ собирает
работу этой роли из всех недель в единое ТЗ: зона ответственности, суставы
(что предоставляешь / потребляешь), понедельные файлы с методами,
зависимости от соседних ролей и личные ворота вех.

| Роль | ТЗ | Зона |
|---|---|---|
| E1 | [role-E1.md](role-E1.md) | Ядро и данные: core, object, component, scene, undo, EditorContext |
| E2 | [role-E2.md](role-E2.md) | Рендеринг: Vulkan, PBR, тени, FrameBuilder |
| E3 | [role-E3.md](role-E3.md) | Редактор (.NET): Avalonia, докинг, гизмо, Inspector |
| E4 | [role-E4.md](role-E4.md) | Рантайм и скриптинг: физика, hostfxr, плеер, managed |
| E5 | [role-E5.md](role-E5.md) | Пайплайн, ассеты, пакеты: CMake, CI, импортеры, package |

Читать вместе с пофайловой детализацией по неделям
([week1-files.md](week1-files.md) … [weeks7-8-files.md](weeks7-8-files.md)):
роль-документ отвечает «что делает конкретный человек весь срок»,
неделя-документ — «что происходит на неделе у всех сразу». Общая стратегия
и риски — в [plan-8-weeks-team.md](plan-8-weeks-team.md).
